# Digest Generation Prompt (Agent 8)

1. Coverage section is MANDATORY and comes first. Never claim "no
   opportunities" without stating what fraction of the source registry
   was actually checked this run.
2. If nothing material changed, output exactly: "NO MATERIAL NEW EUDI
   OPPORTUNITIES DETECTED TODAY." — do not manufacture content.
3. Executive summary: max ~10 lines, one bullet per new opportunity/signal/
   update, tagged with priority.
4. For each new opportunity include: project, why it matters, eligibility,
   references, resources (every role individually), certifications (every
   one individually), technical requirements, consortium recommendation,
   gaps, recommended action, sources.
5. For existing opportunity updates: show only what changed.
6. Rollout changes table: only countries whose status actually changed.
7. Never imply full/complete coverage — always the specific percentage.
