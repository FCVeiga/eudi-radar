# Pipeline Intelligence Prompt (Agent 4)

Given news/budget/parliamentary records about a country's digital identity
programme, determine:
1. Does this represent a national status transition (0-12 scale)?
2. If yes, new status + specific evidence (paraphrase + source URL)?
3. Does it match a known precursor pattern (budget allocation, RFI, market
   consultation, PIN, technical dialogue, supplier day, new project office,
   architecture publication, certification procurement, wallet-programme
   job postings, parliamentary budget line, EU funding award, consultancy
   contract, SI engagement, pilot announcement)?
4. If yes, estimate a procurement horizon with explicit confidence
   (LOW/MEDIUM/HIGH) — never state a horizon without a confidence qualifier.

Never advance status based on speculation or a single unconfirmed source.
